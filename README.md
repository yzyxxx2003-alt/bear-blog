# 小熊手记

简体中文个人博客，使用 [Hugo Bear Blog](https://github.com/janraasch/hugo-bearblog)。

- 文章放在 `content/blog/`。合并或提交到 `main` 后，GitHub Actions 会构建并发布网站。
- `.pages.yml` 已配置文章的标题、日期、草稿、正文和图片上传。以后可以在 [Pages CMS](https://app.pagescms.org/) 中仅为本仓库授权，选择 `main` 分支开始可视化写作。草稿应在发布前关闭。
- 网站首页和关于页分别在 `content/_index.md` 和 `content/about.md`。
